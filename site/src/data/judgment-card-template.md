# 判断卡 · 标准模板（一页纸）

> 用途：给一个**重大、有后果、会被追问**的判断做记录。
> 用法：复制下面「空白模板」那一节，填完就是一张卡。**填不满，说明这件事还没想清楚，不要下注。**
> 来源：从判断系统 schema 2.1 的字段里提取核心十二项，去掉内部管理字段。

---

## 一、空白模板（直接复制）

```markdown
# JUG-XX-YYYYMMDD-NN  <一句话标题>

## 这张卡要回答的问题
（一句话。必须是问句。问错了，后面全错）

## 竞争假设 A / B / C
- A（基准解释）：
- B（反直觉解释）：
- C（底线解释）：

## 当前押注
（押 A / B / C 里的哪一个。必须是一个明确选项，不能写"视情况而定"）

## 置信度
0.__（给一个数字，不要写"比较有把握"）

## 最脆弱的假设
（如果这一条倒了，整个判断就崩。这一栏是整张卡最值钱的地方）

## 反向压力测试
（如果有一个专门唱反调的人，他会从哪里攻击它？）

## 已经观察到的反证信号
- ① 
- ② 

## 失效触发器
（出现什么情况，说明我错了，必须立刻改判）

## 有效期
__ 天（默认 90 天；高频变动的议题 14 天）

## 证据锚点
（每条依据出自哪份材料、哪次访谈、哪一页。不得为空）

## 下一步动作
① 
② 

## 复核触发器
（出现什么事件就提前复核，不必等有效期）
```

## 二、填完自查（8 条，有一条不过就别发出去）

| # | 自查项 | 为什么 |
|---|---|---|
| 1 | **问题是一句问句吗？** | 不是问句的"问题"，通常是伪装的结论 |
| 2 | **假设至少两个吗？** | 只有一个，说明你在确认自己，不是在判断 |
| 3 | **押注是明确选项吗？** | "视情况而定"等于没押 |
| 4 | **置信度是数字吗？** | "比较有把握"没法被检验，也没法被校准 |
| 5 | **最脆弱的假设写了吗？** | 写不出来，说明还没找到命门 |
| 6 | **失效触发器是"可观察的事实"吗？** | "效果不好"不可观察；"连续三个月 X 指标低于 Y"才可观察 |
| 7 | **证据锚点全部有出处吗？** | 找不到出处 → 降格为「待观察」，不许写成结论 |
| 8 | **有效期填了吗？** | 判断会过期，必须写进卡里，不能靠记性 |

## 三、填写示例（公开卡）

### 示例 · 一条理论判断怎么写成可被检验的卡

```markdown
# JUG-TW-20260815-02  稀缺性只会搬家，不会消失

## 问题
技术革命究竟会消灭稀缺性，还是只把它搬到上游？

## 竞争假设
- A（基准）：稀缺性只搬家——摧毁下游执行稀缺，在上游制造更陡的新稀缺
- B（反直觉）：全面通缩——连问题定义与权衡也被自动化，所有认知要素失去稀缺性
- C（底线）：稀缺性只留在物理与牌照等制度性刚性资产上

## 当前押注
押 A。置信度 0.60。

## 最脆弱的假设
社会协作与商业契约依然建立在"主体责任可追溯"之上。

## 失效触发器
① 一个完整技术周期内（3–5 年），初级认知劳动普遍贬值，而全行业**未出现任何一类**判断/架构类角色的报酬溢价扩大；
② 顶端决策岗与基层执行岗的薪酬倍数连续三年收窄；
③ 法律制度正式确立无肉身实体的 AI 自主承担民事与刑事责任。
```

> 这张卡是**公开**的：https://tommywang.cn/research/ledger/

## 四、四条填写纪律（比模板更重要）

1. **依据不能为空。** 找不到出处的想法，只能降级为"待观察"，不许写成结论。
2. **有效期写进制度，不靠记性。** 到期未复核自动降级为"观察中"（默认 90 天；高频议题 14 天）。
3. **改判只追加，不覆盖。** 旧卡留着，另写一条：改判前押什么、改判后押什么、为什么变。写成一样就直接报错——没有实质变化就不该产生一条改判记录。
4. **允许"暂不下注"，但要写清在等什么信号。**

---

## 五、不要给每件事建卡

判断卡只为**重大、有后果、会被追问**的事建。一个项目十来张已经不少；一个部门三到五张够了。

**工序服务于关键判断，不是给每句话上枷锁。**
