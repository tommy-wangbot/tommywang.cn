# 读懂上面怎么解题：六个观察问题（一页纸）

> 用途：身处大型、层级清楚的组织里，想让方案进得了决策桌面，又不被既有的解题方式带偏。
> 来源：我写的《一把手的认知吸引子》。**这是一个观察假设，不是预测工具，不能用来猜下一项具体措施。**

---

## 一、先问：上面习惯把问题翻译成什么

当新的问题出现，观察讨论会不会被带到下面这六类变量上。每次有新议题，各记一行：

| # | 观察变量 | 要问的问题 | 这一轮的观察（自己填） |
|---|---|---|---|
| 1 | 总部与基层的关系 | 总部是自己干，还是负责指导监督？ | |
| 2 | 条线与属地 | 专业条线和属地单位，谁说了算？ | |
| 3 | 职责 | 这件事的责任放在哪里？ | |
| 4 | 权力 | 权力应该给谁？ | |
| 5 | 人员配置 | 人怎么配，编制怎么核？ | |
| 6 | 考核 | 最后用什么把责任压实到人头？ | |

---

## 二、再问：这个翻译有没有过滤掉真问题

每个议题落到上面六类之后，再多问一句：

| 组织的解释 | 还有没有另一种解释 |
|---|---|
| 员工动力不足 → 职责不清、考核没压实 | 薪酬缺乏竞争力？晋升空间有限？业务本身没有增长机会？ |
| 基层承接不了 → 总部专业指导不够 | 人员知识结构与业务要求之间确有差距？ |
| 经营不好 → 内部治理要调整 | 客户流失、产品竞争力下降、行业需求收缩？ |
| 总部和基层争职责边界 | 业务本身就需要跨边界协同？ |

> **判断规则**：如果每个问题最后都被翻译成同一套语言，真正的问题可能一直没人碰。

---

## 三、两张地图

你需要同时拿着两张地图：

- **一张是组织正在使用的问题地图**，让方案能进入决策系统；
- **一张是真实世界可能存在的问题地图**，提醒决策者"这个问题，还有没有另一种解释"。

---

## 四、这张表不能做什么

1. **不能预测下一项具体措施。** 能提高判断概率的，只是"某类问题进入议程之后，更可能被怎样解释"。
2. **不是迎合领导。** 看懂上面怎么想，不等于猜他想听什么。
3. **只适用于大型、层级清楚的组织。** 小公司、扁平组织、一把手频繁更换的组织，未必适用。
